# mac-m5-pro

**Device:** Apple M5 Pro (macOS 26.5, arm64), Python 3.13.14. The development machine, otherwise idle during the runs; local models on Metal where the module supports it (phonon `auto`, qwen3), CPU elsewhere.

**Network:** home fibre connection, Paris; provider regions as routed from there. API numbers include that path.

**What:** every module and model the matrix enables, plus the opt-in `gpt-4o-mini-tts-2025-12-15` snapshot and the kokoro int8/fp16 exports, at 1 warm-up + 20 measured runs per cell (Gemini: 10 at best, see Notes), stream token delay 0 ms. Thirteen runs on 2026-10-27/28/29, listed in `runs.json` and read in `RESULTS.md`: the bulk pass, an ElevenLabs re-run after a credit top-up, the gated phonon 40m models, the OpenAI Realtime entries re-measured on the held-socket module (git `440c60e`), the openai-compatible models including all three `gpt-4o-mini-tts` ids, Deepgram and Cartesia re-measured on their held-socket modules (git `418857e`), the CPU-oriented pocket and phonon variants, the kokoro int8/fp16 exports, and two Gemini runs; then on 2026-10-29 the eighteen `threads`-capped entries (phonon 31m, kokoro, piper at one, two and four threads) and every other local entry re-measured, both with the CPU and memory columns.

**Notes:** the first run exhausted the ElevenLabs credits 4 minutes in, so every ElevenLabs entry comes from the 17:16 re-run. The OpenAI Realtime rows are from the held-socket module only; the socket-per-utterance numbers (1.24 s mean for 2.1-mini) are quoted in `RESULTS.md`, not kept here. `mistral/voxtral-mini-tts-2603` only ever errored (the API rejects `voice_id` for it). Gemini is limited by this key's tier to 100 requests per model per day: `3.8-flash-tts` and `3.8-flash-lite-tts` come from a run stopped by that quota (each lacks a cell), the 3.1 and 2.5 previews from a 10-run pass. Provider latency depends on the hour: ElevenLabs `flash_v2_5` reproduced within 15 ms across two runs, the full OpenAI Realtime 2.1 model swings ±0.3 s. Every local entry was measured on 2026-10-29 with the CPU sampler and the memory reading (CPU in percent of one core, every thread summed; the Mac has 15 cores); the hosted entries come from the earlier runs and read `—` in those columns.
