# OpenAI module

**Status:** Done

Implements [specs/modules/openai.md](../specs/modules/openai.md): an API-backed `openai` backend on OpenAI's `/v1/audio/speech` through the `openai` 3.x SDK, behind an `openai` extra with a lazy import, streaming raw `pcm` (s16le, 24 kHz by default) with an odd-byte carry and 100 ms slices, `base_url` + `sample_rate` for OpenAI-compatible servers (a WAV body rejected), both input shapes (`synthesize_text`, and `synthesize_text_stream` by sentence grouping), faked-SDK unit tests and a live `MODULES` row gated on `OPENAI_API_KEY`. Deliberately leaves out the spec's deferrals: the Realtime successor, sentence prefetching, splitting inputs over 4096 characters, custom voices and `stream_format`.

## Steps

1. **Packaging.** Add the `openai` extra after `cartesia` and put it in `all`; `uv lock` and `uv sync --dev`. Confirm `uv run python -c "from openai import OpenAI"` imports.

2. **Module** (`modules/openai/module.py`, `__init__.py`).
   - Constants: `_DEFAULT_SAMPLE_RATE = 24000`, `_DEFAULT_MODEL = "gpt-4o-mini-tts"`, `_SPEED_RANGE = (0.25, 4.0)`.
   - `__init__`: lazy import first, then `_resolve_api_key` (the ElevenLabs rules, messages naming "OpenAI module"), `voice`, `model`, `instructions`, `speed` (number, not bool, finite, in range), `base_url`, `sample_rate` (int, not bool, `> 0`, `24000` unless `base_url`). Build `OpenAI(api_key=key, base_url=...)` with `base_url` only when set; keep `self._request_kwargs` = `model`, `voice`, `response_format="pcm"`, plus `instructions` / `speed` when set; slice size `2 * (sample_rate // 10)` bytes.
   - `_generate(text, callback, stop)`: return at once on blank text; enter `self._client.audio.speech.with_streaming_response.create(input=text, **kwargs)` via an `ExitStack` inside a `try` → `TTSError("OpenAI request failed: …")`; loop while not `stop`: `next(chunks)` inside the provider `try`; on the first bytes, `RIFF` → `TTSError`; prepend the carried byte, keep `len % 2` for the next chunk, feed `pcm[i:i + slice]` slices, checking `stop` before each.
   - `synthesize_text`: `run_cancellable_worker` around `_generate`. `synthesize_text_stream`: `run_text_stream_worker` with a worker iterating `segment_sentences(pieces)` → `_generate` per sentence, returning early if `stop` is set.
   - `log = logging.getLogger(__name__)`; no per-chunk logging.

3. **Registry.** Import `OpenAIModule`, add `"openai": OpenAIModule`, list `openai/` in the docstring.

4. **Unit tests** (`tests/modules/test_openai.py`). Fake `openai` in `sys.modules` (`types.ModuleType`): an `OpenAI` class recording `__init__` kwargs; `audio.speech.with_streaming_response.create(**kw)` recording kwargs and returning a `_FakeResponse` (context manager with `iter_bytes()` over scripted chunks, `closed` flag, optional raise-on-enter / raise-on-next, optional blocking mode that signals `reached` and waits). Cover every bullet of the spec's "Testing → Unit" list, within the 5-second budget.

5. **Lazy-import guard.** `"openai"` in the poisoned names, `"openai"` in the expected registry set, `("openai", {"type": "openai", "api_key": "k", "voice": "v"})` in the construction loop.

6. **Live row.** `_REQUIRED_IMPORT["openai"] = "openai"`, an `_OPENAI_CONFIG` (`api_key_env: "OPENAI_API_KEY"`, `voice: "marin"`) and `pytest.param("openai", _OPENAI_CONFIG, id="openai")`. Add `OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}` to the CI live step.

7. **Example and docs.** `examples/config.openai.json`; the README, AGENTS.md and cross-spec edits listed in Scope.

8. **Statuses.** Spec to `Implemented` (file and index), this plan to `Done` (here and in [_index.md](_index.md)).
