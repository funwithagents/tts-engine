# Phonon module

**Status:** Done

Implements [specs/modules/phonon.md](../specs/modules/phonon.md): a local-model `phonon` backend on Gradium's `ptts` runtime (no torch), behind a `phonon` extra with a lazy import, native 24 kHz, both input shapes (`synthesize_text`, and `synthesize_text_stream` by sentence grouping as pocket does), faked-library unit tests and a live `MODULES` row that runs in CI with no key. Deliberately leaves out the spec's deferrals: the thread-count knob, `seed`/`eos_threshold`/`rewrites`/`conditions`/`voice_catalog`, voice cloning, and native text-in streaming.

## Steps

1. **Packaging.** Add the `phonon` extra and put it in `all`; `uv lock` and `uv sync --dev`. Confirm `uv run python -c "import ptts; print(ptts.__version__)"` prints `0.4.2` (or a later 0.4.x).

2. **Module** (`modules/phonon/module.py`, `__init__.py`).
   - Module-level constants: `_LANGUAGES = {"en", "fr", "de", "es", "pt", "none"}`; `_to_int16_pcm(chunk) -> bytes` (`np.asarray(chunk, dtype=np.float32).reshape(-1)`, clip in place, `* 32767.0`, `astype("<i2").tobytes()`).
   - `__init__`: validate in the spec's order (`language` defaults to `"en"`), each failure a `ConfigError` naming the field. A small `_number(config, key, *, minimum=None)` helper rejects booleans and non-numbers. Resolve `model`: keep values starting with `hf://`, else `str(resolve_path(config, model))`. Resolve `voice`: a value ending in `.safetensors` becomes `voice_file = resolve_path(...)` and `voice_name = voice_file.stem`; anything else is a name.
   - Then the lazy `import ptts` with the install hint; build kwargs from set fields only (`lang` always — the configured value or `"en"`, `None` for `"none"`; `device` omitted for `"auto"`; `voice` only for a name).
   - Load: `try: tts = ptts.TTS(**kwargs); if voice_file: tts.add_voice(voice_name, str(voice_file))` with `except (ValueError, NotImplementedError, LookupError, FileNotFoundError) as exc: raise ConfigError(f"Phonon module: {exc}") from exc` **before** `except Exception as exc: raise TTSError(f"phonon model load failed: {exc}") from exc` (`FileNotFoundError` is an `OSError`, and other `OSError`s are load failures). `ConfigError` subclasses `ValueError`, so make sure the module's own validation runs outside this `try`.
   - Store `self._tts`, `self._voice` (name, stem, or `None`), `self._sample_rate = int(tts.sample_rate)`.
   - `_generate(text, callback, stop)` exactly as the spec's snippet; `synthesize_text` wraps it in `run_cancellable_worker`; `synthesize_text_stream` runs `run_text_stream_worker` with a worker that iterates `segment_sentences(pieces)` and calls `_generate` per sentence — the pocket module's structure, copied rather than shared (two call sites do not justify a base-class helper).
   - `log = logging.getLogger(__name__)`; one `log.info` after load naming checkpoint, device and quant (`tts.device`, `tts.quant`), nothing per chunk.

3. **Registry.** Import `PhononModule` in `modules/__init__.py`, add `"phonon": PhononModule`, and add `phonon/` to the docstring's package list.

4. **Unit tests** (`tests/modules/test_phonon.py`). A fixture builds the fake `ptts` module (`types.ModuleType`) with `TTS`, `AudioStream`-like class and a `DEFAULT_MODEL` string, injected with `monkeypatch.setitem(sys.modules, "ptts", fake)`; the fake constructor can be told to raise a given exception. Cover every bullet of the spec's "Testing → Unit" list. For cancellation: the fake stream's `__next__` blocks on a `threading.Event` after signaling an `asyncio`-side event that it was reached; the test cancels the task once reached, releases the fake, and asserts `closed` was set before `CancelledError` surfaced. For the text stream, reuse the "audio before the source finishes" shape from [the streaming-text-input plan](202610261140_streaming-text-input.md), step 3. Keep the file in the 5-second budget: no sleeps, no real `ptts`.

5. **Lazy-import guard.** Add `"ptts"` to the poisoned names, `"phonon"` to the expected registry set, and `("phonon", {"type": "phonon"})` to the construct-and-expect-hint loop.

6. **Live row.** In `tests-e2e/support.py`, add `"phonon": "ptts"` to `_REQUIRED_IMPORT` and `pytest.param("phonon", {}, id="phonon")` to `MODULES` with a comment matching pocket's ("local model, no `api_key_env`; gated on the `phonon` extra").

7. **Example and docs.** Write `examples/config.phonon.json`; make the spec, README, AGENTS.md and CI-cache edits listed in Scope. The README `phonon` section states plainly that non-English speech needs a gated CC BY-NC checkpoint and `HF_TOKEN`.

8. **Spec frontmatter.** Add `src/tts_engine/modules/phonon/__init__.py`, `src/tts_engine/modules/phonon/module.py` and `tests/modules/test_phonon.py` to the spec's `code:`/`tests:` lists, now that they exist (`tests/test_project_map.py` rejects paths that do not, so the spec could not name them ahead of the code).

9. **Statuses.** Flip `specs/modules/phonon.md` to `Implemented` (file and `specs/_index.md`) and this plan to `Done` (here and in [_index.md](_index.md)).
