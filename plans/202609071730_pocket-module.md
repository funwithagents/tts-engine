# Pocket TTS module

**Status:** Done

Implements the settled design in `specs/pocket-module.md` — a local-model `TTSModule` wrapping `pocket-tts`, behind a `pocket` packaging extra, lazily imported, native 24 kHz (no resample), auto-detected device, no quantization. Delivers the module, its registration, the extra, the faked-library unit tests, and the live `MODULES` row. Deliberately leaves quantization and any `max_tokens` project default out (see the spec's open questions).

## Scope

- `src/tts_engine/modules/pocket.py` — **new**: `PocketModule(TTSModule)` (lazy import, eager model load, `sample_rate`, `stream`).
- `src/tts_engine/modules/__init__.py` — register `REGISTRY["pocket"] = PocketModule`.
- `pyproject.toml` — add `pocket = ["pocket-tts>=<pinned>"]` under `[project.optional-dependencies]` (drop the commented example there).
- `tests/modules/test_pocket.py` — **new**: unit tests with the `pocket_tts` library faked (no `torch`).
- `tests-e2e/support.py` — add the `pocket` row to `MODULES` and `_REQUIRED_IMPORT["pocket"] = "pocket_tts"`.
- `AGENTS.md` — add `pocket.py` to the `modules/` project-map row; list the `pocket` extra where dependencies/extras are described.
- `specs/pocket-module.md`, `specs/_index.md`, `plans/_index.md` — status upkeep (spec → `Stable` once the API is confirmed, then `Implemented`; plan → `In progress` → `Done`). Also **grow the spec frontmatter**: add `src/tts_engine/modules/pocket.py` to `code:` and `tests/modules/test_pocket.py` to `tests:` once those files exist (they're omitted while the spec is pre-implementation so the drift guard stays green).

## Steps

1. **Confirm the API against the pinned version.** `uv add --optional pocket "pocket-tts"`, then verify in a throwaway REPL/e2e run: `TTSModel.load_model(language=...)`, `model.to(device)`, `get_state_for_audio_prompt(voice)`, `generate_audio_stream(state, text, max_tokens=...)`, `model.sample_rate`, and the yielded chunk type. Resolve the spec's open question #1; pin the version in `pyproject.toml`. Promote `specs/pocket-module.md` to `Stable` (or amend the design if the API differs).
2. **`pocket.py`:** implement `PocketModule`:
   - `__init__(config)`: validate `voice`/`language`/`device`/`max_tokens` (→ `ConfigError`); lazy `from pocket_tts import TTSModel` wrapped in `try/except ImportError` → `ConfigError` with the extra hint; resolve `device` (auto → mps/cuda/cpu); `load_model(**{"language": language} if language else {}}).to(device)`; `voice_state = model.get_state_for_audio_prompt(voice)`; store `model.sample_rate`.
   - `sample_rate` property returns the stored native rate.
   - `stream(text, options, callback)`: run the `generate_audio_stream` loop in `asyncio.to_thread`; convert each float tensor to signed-16 LE mono bytes (`_to_int16_pcm`: cpu/numpy, clip `[-1,1]`, `*32767`, `astype("<i2")`, `.tobytes()`); call `callback` outside the provider `try` so playback errors keep their identity; wrap synthesis errors in `TTSError`; cooperative stop between chunks on cancellation.
3. **Register** `PocketModule` in `modules/__init__.py`.
4. **Unit tests (`tests/modules/test_pocket.py`)** with `pocket_tts` faked via `monkeypatch`/`sys.modules` (a stub `TTSModel` yielding fake float chunks, exposing `sample_rate`): missing-extra `ConfigError`; invalid `device`/`max_tokens`/`voice` `ConfigError`; device auto-detection; `sample_rate` passthrough; `stream` produces whole-int16 PCM from fake chunks and wraps backend errors in `TTSError`. Must not import `torch`.
5. **Live wiring:** add the `pocket` `MODULES` row (no `api_key_env`) and `_REQUIRED_IMPORT["pocket"] = "pocket_tts"` in `tests-e2e/support.py`; the two per-module scenarios pick it up automatically and skip when the extra is absent.
6. **Docs:** update the `AGENTS.md` project map (`modules/` row) and dependency/extra notes.
