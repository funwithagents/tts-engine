# Pocket 4 upgrade

**Status:** Done

Implements the updated [specs/modules/pocket.md](../specs/modules/pocket.md): `pocket-tts` pinned to `>=4.0.1,<5`, the worker's `stop` event passed into `generate_audio_stream`, the new `config`, `quantize` and `temperature` fields, the library's per-language default voice, local audio and `.safetensors` voice files, and library rejections at load reported as `ConfigError`. Deliberately leaves out the spec's deferrals: `mps` in `auto`, the other generation knobs (`eos_threshold`, `noise_clamp`, …) and a `torchao` dependency.

## Steps

1. **Packaging.** Bump the pin, `uv lock`, `uv sync --dev`; confirm `pocket-tts==4.0.1`.
2. **Module.**
   - `_VOICE_FILE_SUFFIXES = (".wav", ".mp3", ".flac", ".safetensors")`; a `voice` ending in one and without `://` goes through `resolve_path`. `voice` stays `None` when unset.
   - Validate `language`/`config` (non-empty strings, not both; a non-URL `config` resolved with `resolve_path`), `device`, `quantize` (bool, not with `cuda`/`mps`), `temperature` (number ≥ 0, no bools), `max_tokens` — all before the lazy import.
   - Lazy import adds `from pocket_tts.default_parameters import get_default_voice_for_language`.
   - `auto` → `cpu` under `quantize`, else the CUDA check.
   - Build `load_model` kwargs from set fields only (`temperature` → `temp`, `quantize` only when true). In one `try`: load, `.to(device)`, resolve the voice (default from the library helper). `except (ValueError, FileNotFoundError)` → `ConfigError("Pocket module: …")` before `except Exception` → `TTSError("pocket-tts model load failed: …")`.
   - `_generate` passes `stop=stop` (and `max_tokens` when set) as the spec's snippet shows.
   - `log = logging.getLogger(__name__)`, one `log.info` after load.
3. **Unit tests.** Extend the fake: `default_parameters` namespace recording its arguments, `generate_audio_stream` recording `stop`, `load_model` able to raise a configured exception, `endless` generation that also ends when `stop` is set. Add tests per the spec's "Testing → Unit" list; keep the file within the 5-second budget.
4. **README.** Refresh the `pocket` section and its troubleshooting bullets.
5. **Statuses.** Spec back to `Implemented` (file and index), this plan `Done` (file and index).
