# Streaming text input

**Status:** Done

Done note (2026-10-26): unit tier 236 passed in ~1.2 s; live tier 16 passed for all five backends (the new `say_stream` scenario included). Time-to-first-audio measured with a source paced at 60 ms per word (36 words, last piece sent at 2.3 s): **ElevenLabs** first audio at 0.73 s, all audio delivered 1.0 s after the last piece; **Gradium** first audio at 0.63 s, all audio 4.3 s after the last piece (server-side generation at roughly 1.7× real time). Both deliver faster than real-time playback, so the ElevenLabs own-WebSocket-loop deferral is **not needed** for now (recorded in its spec).

Implements the text-stream input shape across the stack: `TTSModule.synthesize_text_stream` (and the rename of `stream` to `synthesize_text`) per [specs/tts-module-interface.md](../specs/tts-module-interface.md) ("`TTSModule` ABC", "Text-stream helpers"), `TTSEngine.say_stream` per [specs/architecture.md](../specs/architecture.md) ("From a text stream") and [specs/audio-sink.md](../specs/audio-sink.md) ("Call discipline"), and the per-backend implementations in the five module specs. Delivers every module in one plan (the method is abstract, so all five must implement it for the suite to pass): native stream-to-stream for Gradium and ElevenLabs, sentence grouping for pocket and audiofile, a tone per piece for tone. Deliberately leaves out a tools/MCP counterpart ([specs/tools.md](../specs/tools.md), "Open questions"), a configurable segmenter cap, and ElevenLabs's own-WebSocket-loop fallback (each spec's deferrals).

Decisions taken with the user and recorded in the specs: a text-source failure **aborts** the utterance and re-raises the source's exception unchanged; `say_stream` accepts a sync iterable for in-memory sequences only and rejects a bare `str`; the segmenter's `max_chars` is a fixed constant.

## Steps

1. **Base contract and helpers** (`modules/base.py`).
   - Rename the abstract `stream` to `synthesize_text`; add the abstract `synthesize_text_stream(text_stream: AsyncIterator[str], options, callback)` with the docstring from the spec.
   - `segment_sentences(pieces: Iterable[str], *, max_chars: int = 200) -> Iterator[str]`: a lazy generator over a `str` buffer. After each piece is appended, repeatedly search the buffer for the earliest sentence end — a regex of `[.!?…]` optionally followed by closing quotes/brackets, then whitespace, or a `\n` — and yield the stripped prefix. If no sentence end and `len(buffer) > max_chars`, cut at the last clause boundary (`[,;:]` + whitespace) else at the last whitespace, yield the stripped prefix, and keep the rest. At end of input yield the stripped remainder if non-blank. Never yield a blank segment.
   - `run_text_stream_worker(text_stream, worker)`: a `queue.Queue` plus an end sentinel; a pump task created with `asyncio.create_task` on the calling loop runs `async for piece in text_stream: if piece: q.put(piece)` then puts the sentinel, recording any exception and setting `stop` on failure. The worker runs via `run_cancellable_worker(lambda stop: worker(_pieces(q, stop), stop))`, where `_pieces` is a generator doing `q.get(timeout=0.05)` in a loop, returning on the sentinel or when `stop` is set. After the worker finishes (normally or not): cancel the pump if still running and await it; if the pump recorded a source exception, raise it (discarding the worker's own error, which was caused by the abort); else re-raise the worker's error if any. On `CancelledError`: cancel the pump, let `run_cancellable_worker` set `stop` and wait for the thread, re-raise.
   - Tests (`tests/modules/test_tts_module_interface.py`): `segment_sentences` table cases — two sentences across pieces, decimal `3.14 is pi.` kept whole, newline cut, closing quote after the period, cap cut at a clause boundary then at whitespace, blanks ignored, remainder at end. `run_text_stream_worker` — pieces reach the worker in order with empties dropped; source exception propagates unchanged after the worker has exited (worker records that its iterator ended and that no callback ran afterward); worker exception propagates unchanged and the source's `finally`/`aclose` ran (pump cancelled); worker returning early cancels the pump; cancelling the coroutine while the source is idle raises `CancelledError` only after the thread exited. Keep every wait event-driven (no sleeps) so the tier stays under its 5-second budget.

2. **Engine** (`engine.py`).
   - `say` calls `synthesize_text`. Add `say_stream(text_stream: AsyncIterable[str] | Iterable[str])`: `TypeError` for a `str`; `_as_async_iterator` returns `aiter(obj)` when it has `__aiter__`, else an async generator over `iter(obj)`; then the same lock / `TTSOptions()` / `try: synthesize_text_stream(...) finally: drain()` shape as `say`.
   - Tests (`tests/test_engine.py`): the fixture's mock gains `synthesize_text` and `synthesize_text_stream` as `AsyncMock`s (rename existing assertions). `say_stream` passes an async iterator yielding the given pieces (the mock's side effect collects them) and `callback=player.feed`; a list is accepted and yields its items; a `str` raises `TypeError` before the module is called; `drain` runs once on success and on `TTSError`; a non-TTS exception from the module (standing in for a source error) propagates and still drains; `say` and `say_stream` serialize under one lock (adapt the existing concurrency test to mix both).

3. **Fixture modules.**
   - `tone`: `synthesize_text_stream` runs `run_text_stream_worker`; the worker keeps a running frame index across pieces and, per piece, emits `round(len(piece) * seconds_per_char * sample_rate)` frames in `_CHUNK_FRAMES` chunks, polling `stop`. Factor the chunk-emitting loop out of `synthesize_text` so both share it.
   - `audiofile`: the worker iterates `segment_sentences(pieces)`, resolves each sentence to a path exactly as `synthesize_text` does (`TTSError` when none), and plays it with the existing read loop, factored into a `_play_file(path, callback, stop)` helper.
   - Tests per the "Testing" bullets in [tone.md](../specs/modules/tone.md) and [audiofile.md](../specs/modules/audiofile.md). The "audio before the source finishes" test shape, shared by every module: an async source yields piece one, then `await`s an `asyncio.Event` the callback sets, then yields piece two — the test asserts the callback was reached while the event was unset.

4. **pocket.** The worker iterates `segment_sentences(pieces)` and runs the existing generate-and-feed loop per sentence (factor it into `_generate(text, callback, stop)` shared with `synthesize_text`). Tests: the fake `TTSModel` records each `generate_audio_stream` text; assert one call per sentence and the audio-before-source-finishes property.

5. **ElevenLabs.** Factor the decode-and-feed loop into `_decode_and_feed(raw_chunks, callback, stop)` (build `_ChunkSource` + `stream_any` inside the `TTSError` boundary, then the existing loop). `synthesize_text` passes the `text_to_speech.stream(...)` iterator; `synthesize_text_stream` runs `run_text_stream_worker` and passes `self._client.text_to_speech.convert_realtime(voice_id=..., text=pieces, model_id=..., output_format="mp3_44100_128", voice_settings=...)`. Tests: the fake client gains `convert_realtime`, which consumes the `text` iterator (recording the pieces) and yields one fake MP3 chunk per piece through the already-faked `miniaudio`; assert the pieces and kwargs reach the SDK, audio reaches the callback before the source finishes, SDK errors become `TTSError`, source errors propagate unchanged.

6. **Gradium.** Add `_consume_stream(pieces, callback, stop)` on the private loop: open `tts_realtime` as today (same setup and `ready` check); create a sender task that loops `piece = await loop.run_in_executor(None, next, pieces, _END)`, buffers until the buffer ends in whitespace (or the iterator ends), `send_text`s each group, and `send_eos` on a clean end only; the receive loop awaits `asyncio.wait({next_msg_task, sender}, return_when=FIRST_COMPLETED)` per message, raising `TTSError` if the sender failed, feeding `audio` messages, stopping on end-of-stream or `stop`. `finally`: cancel the sender if running, then `__aexit__`. `synthesize_text_stream` runs it through `run_text_stream_worker` with `asyncio.run`. Tests per the Gradium spec's "Testing" bullet: the fake `FakeTts` emits an audio message per `send_text`; assert word-boundary grouping, exactly one `send_eos`, audio before the source finishes, sender failure → `TTSError`, source failure → propagated unchanged with the fake closed.

7. **Live tier.** Add `test_module_say_stream_produces_pcm` to `tests-e2e/test_modules.py` (parametrized over `MODULES`): an async source yielding `["Hello directly ", "from the TTS engine. ", "This is the sec", "ond sentence."]` into `TTSEngine(cfg, sink=CaptureSink())` via `say_stream`; assert bytes produced, even length, `drains == 1`. The first sentence is the audiofile row's configured text so that row plays `hello.wav` then `default.wav`.

8. **Docs and statuses.** README and AGENTS.md as listed in Scope.
