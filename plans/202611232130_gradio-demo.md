# Gradio demo

**Status:** Done

Implements `specs/gradio-demo.md`: the engine's demo page, built on `tts_engine.setup` and module-setup's page.

## Scope

- `examples/gradio_demo/` — `app.py` (the app: one `tts` section, the default config, `start`, the Session tab), `session.py` (`SpeechSession`, `describe_result`), `__main__.py`
- `tests/examples/test_gradio_demo.py`
- `pyproject.toml` — the `demo` dependency group (`module-setup[ui]`), synced by default; module-setup from the branch of its page's pull request; `examples` type-checked
- `specs/gradio-demo.md`, `specs/_index.md`, `AGENTS.md`, `docs/setup.md`, `docs/index.md`

## Steps

1. `SpeechSession`: the engine built on an event loop of its own thread; `say` waited on, `interrupt` cancelling the utterance in progress, `stop` closing the engine and the loop; a failed build leaving no thread.
2. The app: one section, the tone fixture as the default, `start` resolving relative paths against the app's folder, the Session tab.
3. Tests, then a live run: checks, start, speak, test, stop on kokoro; piper's extra uninstalled and installed back through the page's model.
