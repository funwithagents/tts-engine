# Per-module e2e architecture

**Status:** Done

Implements the settled behavior in `specs/testing.md` ("Live tier"). Restructures the live tier so a **default module** drives the module-agnostic scenarios (real-hardware `say`, MCP transport) while a **`MODULES` table** drives one parametrized per-backend conformance test, each backend with its own dedicated config. Configs are **hardcoded in `support.py`** (asr-engine style) — the committed `tests-e2e/config.json` is removed. Lands with `elevenlabs` as the only row; pocket-tts adds a second row later. Deliberately leaves the pocket-tts module itself out.

- `AGENTS.md` — update the `tests-e2e/` bullet (no committed config; three scenarios).
- `.gitignore` — drop the `!tests-e2e/config.json` un-ignore exception.
- `tests-e2e/config.json` — **removed** (configs now live in code).
- `tests-e2e/support.py` — replace `CONFIG_PATH`/`load_config`/`require_e2e_config`/`require_env` with hardcoded configs: shared `_ELEVENLABS_CONFIG`, `default_module()`, the `MODULES` param table, `engine_block()`, `require_module()` (skips on unset `api_key_env` **or** a missing backend library/extra), and a shared `CaptureSink`; `start_mcp_server(module_type, module_config, port)` builds the temp config from a `(type, config)` pair.
- `tests-e2e/conftest.py` — `server_url` fixture from `default_module()`.
- `tests-e2e/test_modules.py` — **new**: two parametrized per-module scenarios — `test_module_say_produces_pcm` (capture sink → whole-int16 PCM, drained once) and `test_module_say_completes` (real `AudioPlayer` sink, output stream at the module's declared rate).
- `tests-e2e/test_engine.py` — **removed**: its library-path coverage is now per-module in `test_modules.py`.
- `tests-e2e/test_mcp.py` — module-agnostic transport, default module.

## Steps

1. **`support.py`:** hardcode `_ELEVENLABS_CONFIG` (with `api_key_env`, `voice_id`, `model`); `default_module()` returns `("elevenlabs", _ELEVENLABS_CONFIG)` after `require_module`; `MODULES` holds one `pytest.param("elevenlabs", _ELEVENLABS_CONFIG, id="elevenlabs")` row sharing that dict. Add `CaptureSink`, `engine_block()`, `_REQUIRED_IMPORT: dict[str, str]` (empty for base backends), and `require_module(module_type, config)` (skip on unset `api_key_env`, then on a missing `_REQUIRED_IMPORT` library via `importlib.util.find_spec`). `start_mcp_server` takes `(module_type, module_config, port)`.
2. **`conftest.py`:** `server_url` drives `start_mcp_server(*default_module(), port)`.
3. **`test_modules.py`:** parametrize both `test_module_say_produces_pcm` (capture sink) and `test_module_say_completes` (default real player sink) over `MODULES`. Each calls `require_module`, builds via `engine_block`, `await engine.say(...)`, and asserts robust properties only.
4. **Docs/config:** remove `tests-e2e/config.json` and `tests-e2e/test_engine.py`, drop the `.gitignore` exception, and refresh `specs/testing.md` + `AGENTS.md`.
