# Qwen3 module

**Status:** Done

Implements [specs/modules/qwen3.md](../specs/modules/qwen3.md): a local-model `qwen3` backend running Qwen3-TTS through `qwentts-cpp-python` (GGML, Metal on Apple silicon), behind a macOS-arm64-only `qwen3` extra with a lazy import, native 24 kHz, sentence-by-sentence synthesis for both input shapes, faked-library unit tests and a live `MODULES` row that runs on the Mac and skips in CI. Deliberately leaves out the spec's deferrals: voice cloning (`-Base` models), Linux/Windows wheels, extra sampling knobs, forwarding native logs, local GGUF files.

## Steps

1. **Packaging.** Add `qwen3 = ["qwentts-cpp-python>=0.5,<0.6; sys_platform == 'darwin' and platform_machine == 'arm64'"]` with a comment pointing to the spec, and `qwen3` in `all`. `uv lock`, `uv sync --dev`; confirm `uv run python -c "import qwentts_cpp; print(qwentts_cpp.__version__)"` prints `0.5.0` on the Mac.

2. **Module** (`modules/qwen3/module.py`, `__init__.py`).
   - Constants: `_DEFAULT_MODEL = "Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice"`, `_DEFAULT_QUANT = "Q8_0"`, `_DEFAULT_VOICE = "aiden"`, `_DEFAULT_LANGUAGE = "auto"`, `_SAMPLE_RATE = 24000`; `_to_int16_pcm` as in phonon; `_optional_str` helper raising `ConfigError` naming the field.
   - `__init__`: validate every field; read the kind from the model id (`endswith("-Base")` → `ConfigError`; `-VoiceDesign` requires `instruct` and forbids `voice`; otherwise CustomVoice with `voice` defaulting to `aiden`). `temperature`: a number > 0, not a bool.
   - Lazy `import qwentts_cpp  # pyright: ignore[reportMissingImports]` with the install hint.
   - Load in a `try`: `except ValueError` → `ConfigError(f"Qwen3 module: {exc}")`, then `except Exception` → `TTSError(f"qwen3 model load failed: {exc}")`. Module validation runs outside this `try` (`ConfigError` is a `ValueError`).
   - Post-load: match `voice` against `speaker_names()` and `language` against `["auto", *language_names()]` case-insensitively; on a miss, `tts.close()` then `ConfigError` listing the valid values.
   - Store `self._tts`, `self._language`, `self._voice_kwargs` (`speaker`, `instruct`, `temperature` — only those that apply). One `log.info` after load naming model, quant and `model_type()`.
   - `_generate(text, callback, stop)` as in the spec (`contextlib.closing`, rate check); `synthesize_text` runs it per `segment_sentences([text])` in `run_cancellable_worker`; `synthesize_text_stream` per `segment_sentences(pieces)` in `run_text_stream_worker`.

3. **Registry.** Import `Qwen3Module`, add `"qwen3": Qwen3Module`, and add `qwen3/` to the docstring's package list.

4. **Unit tests** (`tests/modules/test_qwen3.py`). A fixture builds the fake `qwentts_cpp` (`types.SimpleNamespace` with `QwenTTS` whose `from_pretrained` classmethod records args and can raise, `QwenTTSError`), injected with `monkeypatch.setitem(sys.modules, "qwentts_cpp", fake)`. The fake `stream()` is a real generator whose `finally` records closure, so `contextlib.closing` is exercised for real. Cover every bullet of the spec's "Testing → Unit" list; cancellation uses the phonon tests' event-driven shape (a blocking `next` that signals it was reached). No sleeps beyond the phonon pattern's settle check, no real library; stay inside the 5-second budget.

5. **Lazy-import guard.** Add `"qwentts_cpp"` to the poisoned names, `"qwen3"` to the expected registry set, and `("qwen3", {"type": "qwen3"})` to the construct-and-expect-hint loop.

6. **Live row.** `"qwen3": "qwentts_cpp"` in `_REQUIRED_IMPORT` and `pytest.param("qwen3", {"language": "english"}, id="qwen3")` in `MODULES`, with a comment: local model, no key, Apple-silicon extra so it skips in CI.

7. **Example and docs.** Write `examples/config.qwen3.json`; make the spec, README and AGENTS.md edits listed in Scope. The README section states plainly that the extra is Apple-silicon only, how a Linux CUDA user installs the wheel, and the download sizes.

8. **Statuses.** Flip `specs/modules/qwen3.md` to `Implemented` (file and `specs/_index.md`) and this plan to `Done` (here and in [_index.md](_index.md)).
