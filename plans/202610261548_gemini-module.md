# Gemini module

**Status:** Done

Implements [specs/modules/gemini.md](../specs/modules/gemini.md): an API-backed `gemini` backend on Google's Gemini TTS models through the `google-genai` 2.x SDK, behind a `gemini` extra with a lazy import, streaming little-endian 16-bit PCM at 24 kHz with no conversion, both input shapes (`synthesize_text`, and `synthesize_text_stream` by sentence grouping), faked-SDK unit tests and a live `MODULES` row gated on `GEMINI_API_KEY`. Deliberately leaves out the spec's deferrals: sentence prefetching, Vertex AI, multi-speaker and style fields, and Cloud TTS Chirp 3 HD.

## Steps

1. **Packaging.** Add the `gemini` extra after `deepgram` and put it in `all`; `uv lock` and `uv sync --dev`. Confirm `uv run python -c "from google import genai"` imports.

2. **Module** (`modules/gemini/module.py`, `__init__.py`).
   - Constants: `_SAMPLE_RATE = 24000`, `_DEFAULT_MODEL = "gemini-3.8-flash-tts"`, `_MIME = "audio/l16"`.
   - `__init__`: lazy import first, then `_resolve_api_key` (the ElevenLabs rules, messages naming "Gemini module"), `model`, optional `voice` and `language_code`. Build `genai.Client(api_key=key)`; keep `self._model` and `self._config` = `{"response_modalities": ["AUDIO"]}` plus a `speech_config` dict holding only the keys that were set.
   - `_check_mime(mime)`: `TTSError` unless the base type is `audio/l16` and any `rate=` parameter equals 24000.
   - `_generate(text, callback, stop)`: create the generator inside the provider `try`; in a `try/finally` that always calls `chunks.close()`, loop while not `stop`: `next(chunks)` inside the provider `try` (`StopIteration` ends); raise on `prompt_feedback.block_reason`; per candidate, walk the parts, check mime, prepend the carried odd byte, keep `len % 2`, and `callback` the even prefix outside the `try`; after the parts, raise on a `finish_reason` other than `STOP`.
   - `synthesize_text`: `run_cancellable_worker` around `_generate`. `synthesize_text_stream`: `run_text_stream_worker` with a worker iterating `segment_sentences(pieces)` → `_generate` per sentence, returning early if `stop` is set.
   - `log = logging.getLogger(__name__)`; no per-chunk logging.

3. **Registry.** Import `GeminiModule`, add `"gemini": GeminiModule`, list `gemini/` in the docstring.

4. **Unit tests** (`tests/modules/test_gemini.py`). Fake `google` and `google.genai` in `sys.modules`: a `Client` class recording `__init__` kwargs; `models.generate_content_stream(**kw)` records kwargs and returns a real generator over scripted `SimpleNamespace` responses (`candidates[].content.parts[].inline_data`, `finish_reason`, `prompt_feedback`), whose `finally` sets a `closed` flag, with optional raise-on-first-next, raise-mid-stream and blocking modes. Cover every bullet of the spec's "Testing → Unit" list. Keep to the 5-second budget.

5. **Lazy-import guard.** `"google.genai"` in the poisoned names, `"gemini"` in the expected registry set, `("gemini", {"type": "gemini", "api_key": "k"})` in the construction loop.

6. **Live row.** `_REQUIRED_IMPORT["gemini"] = "google.genai"`, a `_GEMINI_CONFIG` (`api_key_env: "GEMINI_API_KEY"`, voice `Kore`) and `pytest.param("gemini", _GEMINI_CONFIG, id="gemini")`. Add `GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}` to the CI live step.

7. **Example and docs.** `examples/config.gemini.json`; the spec, README, AGENTS.md and cross-spec edits listed in Scope.

8. **Spec frontmatter.** Add `src/tts_engine/modules/gemini/__init__.py`, `src/tts_engine/modules/gemini/module.py` and `tests/modules/test_gemini.py`.

9. **Statuses.** Spec to `Implemented` (file and index), this plan to `Done` (here and in [_index.md](_index.md)).
