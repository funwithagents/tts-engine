# Kokoro module

**Status:** Done

Implements [specs/modules/kokoro.md](../specs/modules/kokoro.md): a local-model `kokoro` backend running Kokoro-82M through `kokoro-onnx` (onnxruntime + bundled espeak-ng, no torch), behind a `kokoro` extra with a lazy import. The model and voices files come from a pinned Hugging Face repository by default. The module runs at 24 kHz and synthesizes one `create` call per sentence for both input shapes, with a producer thread one sentence ahead of playback, fed in 100 ms slices. Faked-library unit tests, and a live `MODULES` row that runs in CI with no key. Leaves out the spec's deferrals: misaki G2P, a provider field, quantized/v1.1 exports on the Hub, voice blending, the Mandarin v1.1 model.

## Steps

1. **Packaging.** Add the extra and put it in `all`; `uv lock`, `uv sync --dev`. Confirm `kokoro-onnx==0.6.1` imports. *(Done while validating the spec.)*

2. **Module** (`modules/kokoro/module.py`, `__init__.py`).
   - Constants: `_DEFAULT_VOICE = "af_heart"`; `_DEFAULT_MODEL` / `_DEFAULT_VOICES` as `hf://fastrtc/kokoro-onnx/<file>@8d07950c…` strings, so the defaults go through the same parser as user values; `_LANGUAGE_BY_PREFIX` (the spec's nine letters); `_SAMPLE_RATE = 24000`; `_SLICE_SAMPLES = 2400`; `_POLL_SECONDS = 0.05`.
   - `_parse_hf(value) -> tuple[repo_id, filename, revision | None]`: strip `hf://`, split an `@revision` suffix off the end, require at least three `/`-separated segments; a `ConfigError` naming the field otherwise.
   - `__init__`: validate (`_optional_str` for the four strings; `speed` number in [0.5, 2.0], no bools; language from the prefix table when unset), parse `hf://` values or `resolve_path` the rest. Then the lazy imports (`hf_hub_download`, the three `huggingface_hub.errors` classes, `Kokoro`) with the install hint.
   - Download `try`: `hf_hub_download(repo_id, filename, revision=revision)` for each `hf://` reference; `RemoteEntryNotFoundError`/`RepositoryNotFoundError`/`RevisionNotFoundError` → `ConfigError`, any other → `TTSError("kokoro model load failed: …")`.
   - Load `try`: `Kokoro(model_path, voices_path)`; `FileNotFoundError` → `ConfigError`, any other → `TTSError`.
   - Post-load: voice in `get_voices()`, else `ConfigError`; `tokenizer.phonemize("a", language)` raising → `ConfigError`. One `log.info`.
   - `_create(sentence)`: `create(sentence, voice=..., lang=..., [speed=...])` wrapped in `TTSError`; check the rate; return int16 bytes.
   - `_speak(sentences, callback, stop)`: the spec's lookahead — a daemon producer thread with a `queue.Queue(maxsize=1)`, a local `done` event, polling put/get with `_POLL_SECONDS` timeouts, an end marker, failures passed as items; the worker feeds slices and checks `stop` between them; `done.set()` in `finally`; no join.
   - `synthesize_text` → `run_cancellable_worker` over `segment_sentences([text])`; `synthesize_text_stream` → `run_text_stream_worker` over `segment_sentences(pieces)`.

3. **Registry.** Import `KokoroModule`, add `"kokoro": KokoroModule`, add `kokoro/` to the docstring.

4. **Unit tests** (`tests/modules/test_kokoro.py`). Fakes as described in the spec's "Testing → Unit", installed with `monkeypatch.setitem(sys.modules, ...)` for `kokoro_onnx`, `huggingface_hub` and `huggingface_hub.errors`. Cover every bullet. For lookahead: the fake `create` sets an `threading.Event` per call; the callback for sentence one blocks until the event for sentence two's `create` is set (with a timeout so a regression fails rather than hangs). For cancellation: an endless-ish feed (one long sentence, a callback that signals the loop on first slice), cancel, assert no callback after `CancelledError` and no `create` beyond what had started. No sleeps beyond the existing "count settles" pattern; stay within the 5-second budget.

5. **Lazy-import guard and live row.** `"kokoro_onnx"` poisoned, `"kokoro"` expected, `("kokoro", {"type": "kokoro"})` in the hint loop. In `tests-e2e/support.py`: `_REQUIRED_IMPORT["kokoro"] = "kokoro_onnx"` and `pytest.param("kokoro", {}, id="kokoro")` with a comment matching phonon's.

6. **Example and docs.** `examples/config.kokoro.json`; the spec, README, AGENTS.md and other spec edits listed in Scope. The README section states the GPL note on the G2P dependencies plainly.

7. **Spec frontmatter.** Add `src/tts_engine/modules/kokoro/__init__.py`, `src/tts_engine/modules/kokoro/module.py` and `tests/modules/test_kokoro.py` now that they exist.

8. **Statuses.** Spec to `Implemented` (file and index), this plan to `Done` (file and index).
