# Ownership, close API, bounded provider audio and polled setup

**Status:** Done

Implements the design points settled in [tts-module-interface.md](../specs/tts-module-interface.md) ("Lifetime and ownership", "Bounded unread audio", "What cancellation guarantees"), [architecture.md](../specs/architecture.md) ("Ownership and lifetime"), [audio-sink.md](../specs/audio-sink.md), [mcp-server.md](../specs/mcp-server.md) ("Lifecycle"), [deepgram.md](../specs/modules/deepgram.md) and [cartesia.md](../specs/modules/cartesia.md). It closes point 1 of the suggested order of work in the repository review: an explicit close API with stated ownership, a bound on the audio a native-stream provider can run ahead of playback (the deferred F7), a cancellable and bounded connection setup for Deepgram and Cartesia, Cartesia's context rotation driven by the server's `done` acknowledgement instead of idle timing alone, and Gemini's chunk-size assumption stated where it matters. It deliberately leaves out the shared validation/credential/PCM helpers (point 2) and the documentation restructuring (point 3).

## Scope

- `src/tts_engine/modules/base.py` — `TTSModule.close()` (concrete no-op hook); `open_cancellable(enter, leave, *, stop, timeout)` (a blocking setup run on a helper thread and polled against `stop` and a deadline, the late result released); `cut_at_boundary` / `slice_text` (verbatim slices cut at a sentence end, else whitespace, else hard — moved from the deepgram module and shared with cartesia).
- `src/tts_engine/engine.py` — `close()` (idempotent, waits for the in-flight utterance under the say lock, closes the module), `__aenter__`/`__aexit__`; `say`/`say_stream` raise `RuntimeError` once closed; the text source's `aclose()` is awaited at the end of every `say_stream` utterance when the iterator has one.
- `src/tts_engine/mcp_server_cli.py` — the engine is closed once `uvicorn.run` returns (or raises).
- `src/tts_engine/modules/{openai,gemini,cartesia,mistral}/module.py` — `close()` closes the SDK client. `src/tts_engine/modules/{pocket,phonon,qwen3,kokoro,piper}/module.py` — `close()` drops the loaded model. ElevenLabs, Gradium, Deepgram, tone and audiofile keep the no-op (nothing of theirs outlives an utterance).
- `src/tts_engine/modules/deepgram/module.py` — `timeout` field; setup through `open_cancellable`; the sender admits a `Speak` message only while the audio read but not yet fed is under `_MAX_UNREAD_SECONDS`, and starts a new segment only once the previous `Flush` is answered (one segment at the server, down from two, so the unread bound is the lead plus one segment); a complete text is sent in `slice_text` slices so the gate has a grain; an unanswered `Flush` with no server message for `timeout` is a `TTSError`.
- `src/tts_engine/modules/cartesia/module.py` — `timeout` field (also the socket's `open_timeout`); setup through `open_cancellable`; a reader thread moves events into an inbox so the worker polls the inbox and the socket is always drained (the `max_queue: None` option goes); the same admission gate; a context takes at most one segment (flushed at the first sentence end past 600 characters, 900 at a word boundary) and is ended with `no_more_inputs`; the next context opens only once the previous one's `done` has arrived; the worker ends a context idle past `rotate_after` the same way, so an LLM pause is acknowledged before text resumes; an ended context with no `done` and no server message for `timeout` is a `TTSError`.
- `tests/modules/test_tts_module_interface.py` — `open_cancellable`, `slice_text`, the default `close`.
- `tests/test_engine.py` — close semantics, `async with`, use after close, source `aclose`.
- `tests/test_mcp_server_cli.py` — the engine is closed after uvicorn returns.
- `tests/modules/test_{openai,gemini,cartesia,mistral,pocket,phonon,qwen3,kokoro,piper}.py` — one `close` test each.
- `tests/modules/test_deepgram.py`, `tests/modules/test_cartesia.py` — `timeout` validation, polled setup (cancel during a blocked connect surfaces promptly and the late connection is closed; a connect slower than `timeout` is `TTSError`), the admission gate under a blocked callback (priority 7 of the review), the stall rule; cartesia: segment rotation, the idle context ended by the worker and its `done` awaited before the next context (delayed first audio keeps the audio order), the connect options.
- `tests-e2e/test_modules.py` — the PCM conformance test closes the engine, so every backend's `close()` runs live.
- `specs/tts-module-interface.md`, `specs/architecture.md`, `specs/audio-sink.md`, `specs/mcp-server.md`, `specs/modules/deepgram.md`, `specs/modules/cartesia.md`, `specs/modules/gemini.md`, one "Lifetime" line in each other module spec, `specs/_index.md`, `README.md` — the settled design, statuses kept honest.

## Steps

1. **Shared helpers** in `base.py`: `TTSModule.close` (no-op), `open_cancellable`, `cut_at_boundary` + `slice_text` (deepgram's `_cut` generalized). Unit tests for each.
2. **Engine close** and source ownership: `_closed` flag, `close()` under the lock, `__aenter__`/`__aexit__`, the `RuntimeError` guard inside the lock, `aclose()` of the source in a `finally` after the module call (its failure logged at WARNING when the utterance already failed, raised otherwise — the `cleanup` rule). `mcp_server_cli.main` closes the engine in a `finally` around `uvicorn.run`. Tests.
3. **Module close hooks**: the four SDK clients with a `close` (`OpenAI.close`, `genai.Client.close`, `Cartesia.close`, `Mistral.__exit__`), the five local models dropping their model reference. One test per module through the fakes (a recorded `close`, or a weak reference to the fake model that dies).
4. **Deepgram**: `timeout`; `_synthesize` opens the socket through `open_cancellable` (returns silently on `stop`, `TTSError` on the deadline); `_Session` gains `unread` bytes (reader adds, worker subtracts, both under the one `changed` condition) and `last_message`; the sender's `admit` waits for `unread <= bound` and, at the start of a segment, for the previous `Flushed`, before every `send_text`, polling `stop`; `synthesize_text` feeds `slice_text(text, _SLICE_CHARS)`; `_receive` raises `TTSError` when a `Flush` is unanswered and `now - last_message > timeout`. Tests.
5. **Cartesia**: `timeout` (+ `open_timeout`); `open_cancellable`; `_read` thread + inbox + `unread`/`last_message`; `_Session` tracks `ended` and `done` sets instead of `expired`/`final_id`; the sender's `push` runs its stale check, segment accounting and the push under the session lock, ends a full segment's context and waits (polling `stop`) for the previous context's `done` plus `unread <= bound` before opening the next; the worker ends an idle pushed context under the lock and returns once `sender_done and ended <= done`; stall rule. Tests, including the rotation tests rewritten for the ack.
6. **Specs and README**, statuses: the touched concept specs stay `Implemented` because this plan lands the code with the design; `_index.md` rows updated where the one-line description changed.
7. **Live validation** (keys from `~/.zshrc`): the deepgram and cartesia e2e rows (say, say_stream, both cancels, close); a scratch probe for each with a 60-sentence text and a real-time paced sink logging the peak unread audio (must stay near the 10 s bound plus one segment); a cartesia stream paused 10 s mid-answer (the idle context ended, `done` seen, the rest spoken on a fresh context); a cartesia cancel mid-generation with the default receive queue (returns promptly, socket closed within ~1 s).
